## 1. 設計境界

Q172：停止理由と隔離失敗ラッチは再起動に先立って永続保存・復元され、状態不明時は新規発注禁止。Q173：SQLiteトランザクション型。Q174：`PRAGMA synchronous=FULL` とコミット検証。Q175：`PRAGMA journal_mode=WAL`。Q176：SQLite自動チェックポイントを基本とし、滞留・サイズ・失敗・進捗を監視。Q177～193：WALの独立した複合監視。Q194～199：書き込み結果、二層UUID、事前確定保存、DISPATCHING、結果不明時のブローカー独立照合。

**設定値と永続化の成功確認は別問題。** WAL＋FULLでも電源断・媒体故障・同期応答の虚偽・複数プロセス競合を含む全障害での無損失は証明されない。SQLiteだけで外部ブローカー副作用のExactly Onceは保証されない。Q171における本人の明示的な再開承認はSQLiteチェックポイント成功・プロセス再起動・PRマージのいずれによっても代替できない。

**既存仕様から継承する初期閾値（今回改訂しない）**

| 監視対象 | WARNING | MAJOR | CRITICAL |
| --- | ---: | ---: | ---: |
| WAL物理ファイル絶対サイズ | 64 MiB | 256 MiB | 512 MiB |
| 直近1分のWAL物理増大量 | 8 MiB | 32 MiB | 128 MiB |
| 直近5分のWAL物理増大量 | 32 MiB | 128 MiB | 256 MiB |

Q184の通常監視周期は**10秒**。ただし、DBコミット不明・整合性不明・停止理由復元不能等が判明した場合に10秒や測定窓の満了を待つことは許されない。WARNINGは監視強化、MAJORは新規停止と検証、CRITICALは重大障害通知と安全停止。いずれの閾値も実機負荷による検証前の設計値である。

Q191～193の「書き込み進捗」は物理WALファイルサイズとは別系統で評価する。SQLiteのWALフレーム数やアプリログを実際の累積書込バイトへ無根拠に換算しない。進捗側の数値閾値や観測APIは未決であり、この計画で創作しない。

## 2. 障害注入の実施段階

1. **計画確認（今回）**：全26ケースを仕様IDに紐付け、故障点・期待する停止・証拠を文書化。実際のDB障害注入や復旧処理はまだ行わない。
2. **オフライン模擬設計**：承認後、仮想的なイベント列とモックにより、状態・記録・許可条件の矛盾と自動再送禁止を検証する。
3. **隔離したSQLite試験**：安全重要コードの対象限定実装承認後、実口座/本番DBと無関係な一時フォルダーと合成記録を用い、トランザクション・WAL・プロセス終了・ロック競合・再起動復元を検証する。
4. **障害耐久・復旧試験**：VMスナップショットや隔離試験環境で模擬停止・ディスク不足・外部ライター等を検証。実機/実ブローカーに対する試験や稼働開始には個別の許可を要求する。

**事故防止**：Windowsの実データベース、口座・建玉・注文履歴、利用中の`*.db-wal`/`*.db-shm`を操作/削除しない。故意の全ディスク逼迫やPC電源断は実施しない。本番認証・APIキー・顧客データは一切入力しない。`tests/`の構造検査は本番DBやSQLiteインスタンスを起動しない。

## 3. 予定試験の領域と期待動作

| 領域 | ケース | 最低限観察する証拠 |
| --- | --- | --- |
| 永続化・設定検証 | F01～F05 | WAL/FULL設定の読戻し案、エラー/コミット不明時の拒否、空DB自動初期化禁止 |
| 停止理由復元 | F06～F09 | Q171隔離失敗ラッチ・DD4/5停止と日次停止の独立保持、本人承認前の新規停止 |
| WAL/チェックポイント | F10～F17 | サイズと1分/5分閾値、長期リーダー、進捗と物理サイズ、欠測、外部書き手の監視漏れ |
| 競合・監査 | F18～F20 | SQLiteライター競合、UUID重複、ログと実コミット不一致時の結果不明 |
| 外部注文境界の机上試験 | F21～F24 | PREPARED→DISPATCHING直前/直後クラッシュ、応答不明、`RESPONSE_ACCEPTED`と約定の非同一性 |
| 承認ゲート | F25～F26 | 再起動、CI PASS、PRマージを本人の安全承認に昇格させない |

※F21～F24は**実ブローカーへの注文・送信を伴わない**。試験の正解値には`NEW_ORDER_BLOCKED`、`NO_BLIND_RETRY`、`OUTCOME_UNKNOWN`等の**計画用ラベル**を用いる。これらは完成した状態遷移機械の公式イベント型を確定するものではない。
