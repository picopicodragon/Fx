## 4. 本人審査の順序（PRマージで自動承認しない）

1. この審査表の**内容・優先順位が現状を正しく表しているか**を確認する。ここでは設計論点を整理するだけ。
2. FORM-01〜07の**候補方式・根拠・境界条件**をID単位で個別に検証し、必要な安全重要仕様を本人が明示決定・署名/版管理する。未決のままならNO_GO。
3. G1の対象を3×5へ正式改版する際、旧4×5台帳を保全し、EUR/USD契約属性15項目の実口座出典・観測時刻・独立照合証拠を別承認の安全な手順で確認する。
4. FX-SAF-001/002及びその他の仕様の原議・証拠・失敗試験・安全重要コードに関する個別承認を行う。
5. 実環境MT4の閲覧・単一口座セッション・デモ/本番実行は、それぞれ**別途の明示承認がある場合のみ**検討する。

本人が本PRをマージしても、1〜5の承認やG1解除を意味しない。原議欠落Q148〜199の探索は本人指示により保留するが、未検証の履歴・安全受入ゲートは保持。
