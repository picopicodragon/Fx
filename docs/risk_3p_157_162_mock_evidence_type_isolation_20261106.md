# RISK-3P-157〜162：架空チェーン・二重証人・P05承認分離の型検査

2026-11-06 JST。PR #198のmainマージ確認後、方式Eの独立ブランチで実装。未マージのPR #199〜201とはファイル重複なく安全審査を継続する。

## 見つかった問題

3つの純合成バリデータの`evaluate`は、型を確かめる前に`set(data)`、`set(row)`、文字列の等値比較などを使用していた。また、権限辞書の単純な等値比較はPythonの`False == 0`／`True == 1`により、整数と真偽値の型が置き換わっても等しいと評価する。データクラスでなく組込み辞書を扱うため、任意Pythonオブジェクトの`__hash__`／`__eq__`が実行され得る経路が残っていた。

P49の架空ハッシュチェーンでは、元のsequence/kind等が不正と分かってもハッシュ計算に入力を渡していた。P50の架空一次証人検査は、子評価器が例外終了したとき`evaluate`全体が失敗する可能性があった。P51の`check_id`比較にも、比較前の正確な文字列型検査がなかった。
