## 承認された変更の範囲

**G1の正式な審査対象**を、USD/JPY、EUR/JPY、EUR/USDの3通貨ペアそれぞれについて、主要契約属性5個、計15項目とする。5属性は次の通り。

| キー | 単位・目的 |
| --- | --- |
| `min_lot` | 銘柄の最小注文数量（lot） |
| `lot_step` | 注文数量の増分（lot） |
| `point_quote` | 1ポイントのquote通貨価格幅 |
| `tick_size_points` | 1tickの価格変動をpointで表したもの |
| `tick_value_deposit_currency` | 基準lotにおける1tickの損益価値（入金通貨建て） |

口座通貨、1lot契約サイズ、digits、max lot、stop/freeze level、取引/約定方式、実シンボル表記、時刻/出典、EUR/USD USD→JPY換算は**補助的に必須の検証**として保持する。主要5属性が揃っても、補助検証とFX-SAF/FORM/G1〜G9が未解決なら取引はできない。
