## 修正理由

`scripts/risk_3p_55_synthetic_ingress_contract.py`は、3つの**架空の**ハッシュチェーン・証人・未承認レビューを内部形式だけ確認する乾式受入器である。従来の`package["safety"] != SAFETY`では、Pythonの`False == 0`、`True == 1`のため、権限フィールドがboolからint、intからboolへ改変されても辞書全体が等値と判定され得た。また`set(package)`、不審な`classification`／`source_mode`の比較は、想定外のPythonオブジェクトの独自ハッシュ・比較処理を実行する余地があった。

さらに、子評価器の返却値が組込みdictであることやキー・ステータス値の正確な型を確認せずに`.get()`していた。予期しない子評価器例外の種類によっては、外側の受入検査がPython例外で終了する可能性もあった。
