# P0-01 D5-5：ゼロ損失・異常入力のオフライン安全性検証

作成：2026-10-29。対象：`scripts/p0_01_d5_4_synthetic_risk.py` の合成資金管理テストのみ。

## 変更点
- `single_trade_risk_jpy`、`aggregate_risk_jpy`、`daily_loss_jpy` に限り、文字列 `"0"` を正常なゼロとして受け入れる。
- `equity_jpy` と `peak_equity_jpy` は常に正値必須。ゼロまたは不正値を拒否し、ゼロ割と意味不明なDD算出を防止。
- 欠損、負数、非文字列、NaN、Infinity、指数表現、承認フィールドの混入は `REVIEW_REQUIRED`。ゼロを許可した以外の構文、上限、優先順位は変更しない。
- 原点の厳格化のため、`0.0`など正規形式の非負数文字列は既存の正数パーサーで扱われる一方、数値型の0/0.0は拒否。文字列`"0"`だけをゼロ用の特別ケースとする。

## 変えない仕様
1取引0.5%、同時保有1.0%、日次1.5%、最大ドローダウン5%。DD5%到達 > 日次上限到達 > 取引/同時保有リスク超過の優先順位を維持。
