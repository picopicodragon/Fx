# P0-01 D5-10：停止状態復元と履歴チェーンの合成統合ゲート

2026-10-29。メモリ上の合成データのみでD5-8（停止状態復元）とD5-9（履歴連続性）の両方を照合する。

## 受理条件（それでも実売買禁止）
- 履歴チェーンと復元記録がそれぞれ形式・連番・状態の検査に通過する。
- 復元記録が履歴の末尾と完全一致し、最低sequenceに達している。
- チェーン上の停止ラッチと復元された停止ラッチが一致する。
- 正常な合成履歴でも結果は `INTEGRATED_*_SYNTHETIC_ONLY` / `*_NEVER_AUTHORIZED`。実売買は常に禁止。

履歴欠落、途中欠落、巻き戻り、日付不一致、記録破損、復元の不一致、停止消失、DD5%停止からの降格、無効入力は `INTEGRATION_REJECTED_FAIL_CLOSED` と停止ラッチtrueを返す。

## 限界
メモリ内の同一内容との照合にすぎず、外部からの署名、真正性、削除された履歴の証明、完全な履歴の偽造、実ディスク永続化、電源断、時計の連続性、ブローカー実測値、実注文・決済、再開承認は保証も実装もしない。状態の書込みやMT4接続は一切ない。

`broker_verified=false`、`production_usable=false`、`orders_generated=false`、`terminal_execution_approved=false`、`forward_trading_enabled=false`、`phase_1=BLOCKED`固定。実環境No-Go継続。
