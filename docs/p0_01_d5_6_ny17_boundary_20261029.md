# P0-01 D5-6：NY17:00の合成日次境界テスト

2026-10-29。入力は明示的なUTC時刻のみ。Python標準のzoneinfoでAmerica/New_Yorkに変換し、NY現地17:00を境界とする日次識別ラベルを算出する。

- 夏時間：NY17時 = UTC21時 = JST翌06時。
- 冬時間：NY17時 = UTC22時 = JST翌07時。
- 2026年の米国夏時間開始：3月8日、終了：11月1日。切替日におけるUTC境界を合成テストで確認。
- ラベルは直近のNY17時の**現地暦日**を文字列で返す。週末・休場・祝日・ブローカーの取引日との一致は仮定しない。
- ナイーブ日時、UTC以外のオフセット、形式不正などはREVIEW_REQUIRED。夏冬時間における曖昧な現地壁時計時刻を入力に採用しない。

本工程は「日次区間のラベル」のみ。ニューヨーク17時の実現時刻をシステム時計から取得しない。実損益集計、日次停止の発動、ポジション全決済、翌日の自動再開、スリッページ、時刻同期監視は実装しない。FX市場の週末等の業務運用は別工程。

返却結果は常に `broker_verified=false`、`orders_generated=false`、`terminal_execution_approved=false`、`forward_trading_enabled=false`、`phase_1=BLOCKED`。PHASE-1実環境No-Goを維持。
