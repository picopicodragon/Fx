# P0-01 D5-1：独立デモ環境・実行前チェックリスト（設計のみ）

作成：2026-10-28。対象は既存の楽天MT4デモ環境Aと、未設置の候補B。**本書の作成・PRマージは口座開設、MT4起動、EX4実行の承認にならない。**

## 現状と制約
- A：本人目視でMACD Sampleがチャートとナビゲーターに存在。建玉または未約定注文あり。自動売買表示はOFFに見える。接続状況などの本人目視は独立確認済みとはしない。
- AのEA・チャート・口座・取引・ログ・AutoTradingに変更禁止。Aを観測用プローブに流用しない。
- B：新規独立デモ口座と別MT4インストール・データフォルダが確実に成立する場合だけ将来の候補。現時点で未作成・未承認。
- 楽天MT4デモ口座の同時保有、再作成による旧口座への影響、同時ログイン可否は未確認。証拠がなければB作成はNo-Go。
- デモの仮想資金500万円と本番想定10万円を混同しない。

## 将来の作業手順案（未承認）
1. **事前証拠審査：** PF1が不明なら停止し、オフラインモックを継続。デモ口座を試しに作成しない。
2. **独立環境計画：** 別のインストール先、別のデータフォルダ、ログ保存先、Aのファイル/取引状態に触れない条件を文書化する。
3. **個別承認：** Bのデモ口座作成、MT4インストール、ログインはそれぞれ別の承認を得る。PRマージで代替しない。
4. **Bの安全目視審査：** ログイン先がDemoのみ、EAなし、建玉/注文ゼロ、AutoTradingはOFFのまま。ただしAutoTrading OFFだけではスクリプト実行防止にならない。
5. **読み取り専用コードの別承認：** 対象EX4、読取関数、出力先、1回限りの操作、停止手順を確認。現段階では配置・起動しない。
6. **証跡レビュー：** 機密情報を伏せ、単位/口座通貨/ロット/時刻/出典を別々に検査。承認なしの値はverified_valuesに投入しない。
7. **リスク検証：** 注文する前に別工程でFORM-01/03、価格変動、契約単位、資金制約を検証。読み取りが成功しても売買は許可しない。

## 中断条件（将来の手順検討用）
- Aの建玉・注文・EA・フォルダに変更の可能性が発生、Bとのログイン混同、Liveサーバー表示、予期しない注文/EA発見、データフォルダ分離不能、証跡不足、時刻またはロット単位不明、本人承認未取得ならNo-Go。
- 中断時は**新しい操作を進めず**、本人に状態を報告する。口座を切り替えて試す、EAを削除する、注文を決済する、再起動して様子を見る等の復旧行為も自動実施しない。
- 復旧は「現状記録 → 影響範囲評価 → 個別に承認された復旧案」の順。Aの現状保存を優先し、未承認の現状復帰操作をしない。
- 個人識別情報、ID/パスワード、口座番号、残高、注文詳細、無加工ログはGitHub・チャットへ貼らない。
