# P0-01 D5-16：単一MT4環境の実行前安全確認設計

作成日：2026-10-29。根拠：D5-15改訂（PR #130）、D5-12総合監査、D5-1の旧プレフライト。

**結論：OFFLINE_DESIGN_ONLY / NO_GO / PHASE-1 BLOCKED。** この文書は将来の安全な確認のための計画であり、MT4起動・ログイン・照会・EA実行・発注・決済の許可でも実施記録でもない。

## 1. 環境方針と相反する既存報告

- 本人の最新方針：**単一口座・単一MT4環境**。楽天への問い合わせは行わない。独立デモBの作成・複数口座の並行運用・追加MT4の導入は行わない。
- 本人の最新申告：楽天口座は契約中だが休眠状態、建玉等はない。これは**本人申告（USER_REPORTED）**であり、現在の端末/ブローカー実測ではない。
- 以前の既存デモAの目視報告：MACD Sampleがチャート/ナビゲータにあり、保有ポジションまたは予約注文が存在。AutoTradingはOFFに見える、接続表示はCONNECTED_LIKE等。こちらも過去の目視情報であり、現在値ではない。
- **相違は未解決**。最新の「楽天口座」が以前の「MT4デモA」と同一の口座・サーバー・時点を指す保証がない。古い証拠を削除せず、どちらの申告も実測確認済みに昇格しない。
- 旧D5-1のPF1〜PF4等は独立デモBを前提とする**歴史的設計**であり、本D5-16の単一環境用ゲートに読み替える。D5-13〜D5-14の複数環境案も参照専用。別デモを作って解消する選択肢は採らない。

## 2. 確認段階と権限分離

| 段階 | 範囲 | 許可の状態 | 含まれない行為 |
|---|---|---|---|
| V0 | オフライン机上レビュー・設計・合成テスト | このPRの範囲内 | MT4/口座へのアクセス一切 |
| V1 | 将来の本人による**既に表示された情報の目視**確認方法 | **未承認** | アプリ起動/画面遷移/ログイン/接続/設定変更を自動許可しない |
| V2 | 将来の明示承認を受けた、対象を限定した読み取り専用照合 | **未承認** | MarketInfo/EA/EX4起動、環境変更、注文 |
| V3 | EA/スクリプトに関する限定操作 | **未承認** | 注文・決済・停止解除を含まない |
| V4 | デモ取引操作・実運用への進行 | **未承認 / NO_GO** | V0〜V3の合格から自動的に移行しない |

**許可は個別であり連鎖しない。** 本人が「テストを実行した」「PRをマージした」ことはMT4アクセス承認でない。V1を経ずにV2へ移ることも、操作前の新たな本人承認なしには不可。将来いかなる状態でもデモと本番の区別が付かない場合は安全確認工程を中断する。

## 4. 想定される停止・中断条件

- 対象がデモ/本番のどちらか不明、サーバー表示の不一致、意図しないログインやMT4自動起動の可能性。
- 既存EA/スクリプトに注文機能が残存、注文/予約注文の有無が不明、最新申告と過去の報告の差が解消されない。
- AutoTrading OFF表示のみを根拠に安全と判断しようとした、EAの停止・削除・再装着が必要になった。
- 4ペア×5項目、損失集計、NY17区切り、再起動時停止状態、ブローカー権限が不明。
- 未承認の口座照会・MT4起動・ログイン・ファイル操作・EX4実行・注文・決済が必要になった。

中断時は**新しい操作を進めない**。既存EAや注文を停止/変更/削除/決済する自動復旧操作も行わず、状態を人間に報告して別途対応方針を承認する。安全判断に必要な情報がないとき「建玉なし」「注文可能」とは推測しない。

- 誤接続防止と証拠の非改変性を個別レビューする。単一環境だから安全と決めつけない。
- 将来のV1/V2確認も運用許可やG1のブローカー契約値確定とは別。
