# FX-FWD-011/012: フォワード監視証拠の停止ゲート

## 実装範囲
`research/forward_evidence_gate.py` は、FWD-01観測ジャーナルの完全監査を前提として、FWD-03品質評価、FWD-02B公式BLS予定スナップショット、FWD-05仮想ポジション報告を**オフライン**で統合診断する。FWD-011は情報品質・イベント停止診断、FWD-012は単一仮想取引の上限確認と未認定リスクの可視化。情報入手、外部API推論、注文送信、MT4通信、Windowsタスクの登録は一切実行しない。

- 価格の90秒超過/欠損、遅延、ソース時刻逆行、時刻の独立証明欠落を検出。
- 公式BLS将来予定のスナップショットを任意入力で参照。24時間超過、将来時刻の報告、発表時刻±15分を警戒。BLS予定は**3ペア全ての安全性を認定しない**。その他地域・金融政策・コンセンサス値は網羅されない。
- 仮想損益レポートの同一評価時刻と注文不可フラグを検証し、10万円想定の0.5%（500円）仮想初期損失制限を監査。実際のブローカー約定、単位・換算・証拠金、他の建玉、資産変動は認定しない。
- 1.0%同時リスク、1.5%日次損失、4% LEVEL3、5% DD上限を**正式規定の参照値**として記録し、実口座・仮想累積損益による執行認定は行わない。
- 入力不整合や既存出力衝突はFAIL_CLOSED。出力ファイルは排他的に新規作成。正常入力でも`NO_GO`、`safety_hold_latched=true`、`real_orders_permitted=false`、デモ発注無効を固定。

## Windows実行例（ネット接続・課金なし）

```powershell
python -m research.forward_evidence_gate `
  --store out/forward_observation_20261109 `
  --asof-utc 2026-11-10T01:00:00Z `
  --calendar out/bls_calendar_20261110.json `
  --paper out/shadow_20261110_170000_paper.json `
  --out out/forward_evidence_gate_001.json
```

`--calendar`、`--paper` は未作成なら省略可能。省略時はそれぞれ不足と明示する。**仮想ペーパー報告は`--asof-utc`と同じ時点で作成したものだけ**受理する。上記日時・ファイル名は書式例であり、現実の価格/発表事実を表さない。予定スナップショットは値が検証済みにならず、常に注文不可。

## FWD-013: 複数時点の仮想純資産を用いた研究用リスク履歴

`research/forward_risk_timeline.py`を追加。外部で**仮想計算した**純資産と建玉リスクの時系列だけを受け付け、NY市場17時（夏21:00 UTC、冬22:00 UTC）区切りを`America/New_York`で計算する。口座実資産の自動取得はしない。

```json
{
  "schema": "fx_forward_shadow_risk_timeline_v1",
  "samples": [
    {
      "observed_at_utc": "2026-11-10T22:00:00Z",
      "equity_jpy": "100000",
      "open_risk_jpy": "0",
      "source_status": "HYPOTHETICAL_UNVERIFIED"
    }
  ]
}
```

これは**形式説明のための架空値**。同じ時刻や時刻逆行、NaN、負のリスク、権威を偽装する`source_status`は拒否。5万時点/6MBを上限とする。1日の基準資産はその日の**最初のサンプル**であり、NY17時ちょうどの価格や損失が不明な場合は日次リスクの過少計算があり得るため正式安全認定には使わない。

```powershell
python -m research.forward_risk_timeline `
  --input out/hypothetical_risk_samples.json `
  --out out/hypothetical_risk_report.json
```

DD2%/3%警告、4% LEVEL3（承認解除必要）、5%停止、1.5%日次損失、1.0%超の合計リスクを研究上のアラームとして出力。仮想DD4%/5%を一度超えると以降の仮想資産回復によってラッチを解除しない。**実際の注文、MT4デモ取引、再開承認、証拠金・SL計算、ウォッチドッグには接続しない。** 本番のリスク管理エンジンの認定とは明確に区別する。
