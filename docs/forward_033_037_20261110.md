# FX-FWD-033〜037：安全なローカル証拠監査の一括実行

## 対象
今回の工程は、すでに実装された研究専用FWD-022/023/024/026/028/029〜032を**オフラインで一括監査する仕組み**である。楽天証券へのログイン、MetaEditorコンパイル、実価格取得、継続監視、デモ注文と本番注文は実行しない。

| 工程 | 成果 |
|---|---|
| FWD-033 | `research.forward_offline_batch`：複数の研究レポートを単発評価し、既存安全ゲートの結果を集約 |
| FWD-034 | レシート、観測時刻、前後順序を検証。監査対象と時刻が合わなければFAIL_CLOSED |
| FWD-035 | 研究上の判断が良好でも`NO_GO`固定。未認証情報の危険要因を明示 |
| FWD-036 | `research.forward_bundle_manifest`：6種のローカルJSONファイルをSHA-256で固定し、改ざん・欠損・パス逸脱を拒否 |
| FWD-037 | `scripts/forward_offline_audit_once.ps1`：Windows PowerShellで手動の一回限り実行。タスク登録、ループ、外部接続を行わない |

## 入力資料

FWD-022/023/024/026/028/029の研究報告を6種用意する。未作成のファイルを埋めるために事実を捏造しない。

| `--watchdog` | `research.forward_shadow_watch` |
| `--intake` | `research.forward_source_intake` |

### Windows PowerShell 実行例

```powershell
python -m research.forward_bundle_manifest `
  --reports-dir out `
  --asof-utc 2026-11-10T03:00:00Z `
  --receipt receipt.json `
  --watchdog watchdog.json `
  --intake intake.json `
  --demo demo.json `
  --mt4 mt4.json `
  --calendar calendar.json `
  --out out/fwd_batch_manifest_001.json

.\scripts\forward_offline_audit_once.ps1 `
  -Manifest out/fwd_batch_manifest_001.json `
  -ReportsDir out `
  -Output out/fwd_batch_audit_001.json
```

日時・ファイル名は構文例であり、実運用結果ではない。WindowsのPowerShell実行ポリシーを自動変更しない。出力は新規ファイルのみ。CIはPythonテストの実行を確認するが、PowerShellスクリプトのユーザーPCでの実行やMetaEditorコンパイルは未認定。

3. 現段階でWindowsの定期タスクや自動監視は設定しない。自動復旧・停止レベル解除・承認代行もしない。
4. FX本体の正式リスク上限0.5%/1%/1.5%、DD 2%/3%/4%/5%の実際のMT4口座への適用、情報ライセンス、AI実判断性能の認定ではない。
