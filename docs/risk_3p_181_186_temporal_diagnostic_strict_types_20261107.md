## 検査で見つかった問題

`risk_3p_57_synthetic_temporal_coherence.py`は、2つの架空観測時計の順序・時刻差・継続性を調べる限定的なシミュレータである。以前は、root／各ストリーム／サンプルの辞書を型チェック前に`set(dict)`しており、`origin`、`session_alias`、架空アカウント等の型を調べる前に比較していた。`safety`辞書の単純な等値比較では`False == 0`／`True == 1`による型偽装を見逃す可能性があった。

`risk_3p_58_safe_diagnostic_projection.py`も同様に、外部から渡る架空診断辞書のキーと結果名を比較前に厳格検査せず、`raw_errors`が通常の空配列なのか、独自比較を持つ不審なリストなのかを区別しなかった。ここで入力値がログや公開結果へ転写されない設計を保持しつつ、偽の合成PASSを拒否する。
