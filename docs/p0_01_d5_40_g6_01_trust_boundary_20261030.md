## 1. 必要な5つの権限（分離していても未認証）

| 役割 | 将来の責務・独立性証明 |
|---|---|
| EVIDENCE_PRODUCER | ローカルの履歴/状態を発行。ただし自己申告を独立証拠としない |
| TRUST_ANCHOR_CUSTODIAN | 変更不能・遡及改ざん困難な参照基準と所有/権限を管理 |

## 3. 12種類の拒否すべき脅威

| 脅威群 | 対応する脅威 |
|---|---|
| 同時改ざん | SHARED_ADMIN_AUTHORITY / JOURNAL_ANCHOR_COORDINATED_FORGERY |
| 履歴と発行者の偽装 | LOCAL_ROLLBACK_AND_REPLAY / ISSUER_EPOCH_REBINDING / REVOCATION_TOMBSTONE_ERASURE |
| 分断・通信断 | SPLIT_BRAIN_WITNESS / ANCHOR_TIMEOUT_OR_OUTAGE |
| 時計・プライバシー | FALSE_TIME_FRESHNESS / PRIVATE_DATA_IN_ANCHOR |
| 排他/復旧/承認 | SINGLE_WRITER_FENCE_BYPASS / HOST_REBOOT_WITHOUT_PROOF / APPROVAL_OR_KEY_REVOCATION_SPOOF |

**全12脅威の原則：** `DENY_AND_HOLD_STOP`、`REQUIRES_DESIGN_AND_INDEPENDENT_PROOF`。未検証の実行・復旧・失効取消し・停止解除を自動で行わない。どの候補でも署名済みという申告だけでは再生攻撃と巻戻しを防げない。独立基準が通信断で利用できない場合も新規注文/停止解除を許可しない。G2の機密口座・秘密鍵・生ログを独立Anchorの公開用メタデータへ送ってはならない。
