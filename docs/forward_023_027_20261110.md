# FX-FWD-023〜027：フォワードデモ移行準備のオフライン監査

## 概要
本段階は、既存の3ペア（USD/JPY、EUR/JPY、EUR/USD）に対する**研究観測データと安全停止の監査**を強化する。楽天MT4の実機起動・コンパイル・デモ口座照会・発注は行わない。各結果は`NO_GO`固定。

| 工程 | 新規モジュール | 実装と限界 |
|---|---|---|
| FWD-023 | `research.forward_mt4_export_series` | 既存読み取り専用CSVの複数ファイルをオフライン照合。DEMO表記は自己申告、90秒以内のタイムスタンプ・ペア別時刻単調性を検証。MT4実機との接続機能ではない |
| FWD-024 | `research.forward_calendar_revisions` | オペレーター保存済みの同一公的予定ソースの前後スナップショットを比較し、追加/時刻変更/消失を記録。消失=正式な発表中止とは解釈しない。FRB/ECB/BOJへの自動アクセスは未実装 |
| FWD-025 | `research.forward_shadow_watch` | FWD-018/019の監査レポートを統合した一回実行型の研究用監視 |
| FWD-026 | 同上 | 60秒LEVEL1/600秒LEVEL2の研究用観測欠損検知、直前停止ラッチの継承。自動再開・外部通知・MT4双方向ウォッチドッグは未実装 |
| FWD-027 | `research.forward_demo_gate_board` | FWD-022/023/024/026の結果を集約し、準備未充足を可視化。**良好なローカル入力でもデモ注文を許可しない** |

## 実行例（Windows PowerShell）
下記は**書式例**であり、実データや運用実績を示さない。入力は利用者が自分の端末で取得・保存したものに限る。出力は既存ファイルの上書き不可。

```powershell
python -m research.forward_mt4_export_series `
  --csv out/mt4_quote_001.csv `
  --csv out/mt4_quote_002.csv `
  --asof-utc 2026-11-10T01:00:00Z `
  --out out/mt4_export_series_001.json

python -m research.forward_calendar_revisions `
  --previous out/bls_schedule_previous.json `
  --current out/bls_schedule_current.json `
  --out out/bls_calendar_revision_001.json

python -m research.forward_shadow_watch `
  --observability out/forward_observability_001.json `
  --quote out/forward_quote_continuity_001.json `
  --asof-utc 2026-11-10T01:00:00Z `
  --out out/forward_shadow_watch_001.json

python -m research.forward_demo_gate_board `
  --demo out/forward_demo_readiness_001.json `
  --watch out/forward_shadow_watch_001.json `
  --mt4 out/mt4_export_series_001.json `
  --calendar out/bls_calendar_revision_001.json `
  --out out/demo_gate_board_001.json
```

次回監視では、`research.forward_shadow_watch --prior out/forward_shadow_watch_001.json` を追加し、過去停止ラッチを引き継ぐ。ラッチ解除のために`--prior`を省略してよいという意味ではない。**継続監視の長期実行、自動復帰、時計の単調増加証明には未対応**。実運用のウォッチドッグとして利用禁止。

## 安全上の重要な未完了事項
- FWD-023：楽天デモMT4への読み取り専用コード導入とコンパイル・実動作・サーバーティック時刻照合。
- FWD-024：BLS以外の中銀・指標発表予定について、公式ソースと利用条件の確認、明示オプトイン取得、更新差分の真偽確認。
- FWD-025/026：長期運転・Windowsタスクスケジューラ・復旧後安全条件・独立ウォッチドッグ/通知経路。現段階は**入力ファイルの一回限りの研究監査**。
- FWD-027：デモ発注の安全承認を自動生成/代行しない。保有ポジション、口座純資産・日次損失・DD管理、証拠金、送注文経路は実証されていない。

正式リスク制約の0.5%/1.0%/1.5%/DD5%、DD4%の人間承認要件、通信60秒/10分の停止管理は別途本体安全ゲートで維持する。研究監査を本体と同等に扱わない。

全出力は`runtime_go_no_go=NO_GO`、`safety_hold_latched=true`、`real_orders_permitted=false`。実注文・デモ注文無効のまま。既存口座の複数環境からの同時接続や別デモ口座追加を要求しない。
