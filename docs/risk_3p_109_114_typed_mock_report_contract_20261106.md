# RISK-3P-109〜114：合成損失引継ぎの型・フィールド構造の厳密照合

2026-11-06 JST。PR #191とPR #192がいずれもmainへマージ済みであることをGitHubで確認し、最新mainから新ブランチで作業を実施。

## 発見と修正理由

前工程の`review_synthetic_loss_handoff`は架空チケットとポートフォリオ入力を1対1照合し、損失額を再計算している。ただし再計算レポートと受取レポートの比較にはPythonのデータクラス等価比較を使っており、**`False == 0`、`True == 1`、同値を持つタプル派生型**が同一と判断される可能性があった。また、凍結データクラスのインスタンスに`object.__setattr__`で想定外のフィールドを足しても、標準のデータクラス等価比較はそれを比較対象に含めない。さらに、報告欄へ独自の`__eq__`を持つオブジェクトを埋め込むと、その等価比較を実行する可能性がある。

これらは**オフライン合成レポートの型・スキーマ検証不足**であり、実ブローカーの発注許可が得られたわけではない。検査器自身の拒否動作を強化する。
