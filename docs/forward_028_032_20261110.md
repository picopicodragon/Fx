# FX-FWD-028〜032 研究用フォワード準備強化

正式3ペア：USD/JPY、EUR/JPY、EUR/USD。

## 完了した実装と残存制約

| 工程 | 実装成果 | 実機/実運用で未完了の検証 |
| --- | --- | --- |

CLI実行は下記の通り。入出力ファイルは利用者が別途用意する。すべてオフライン、一回実行、上書き禁止。日付は構文例であり、実測日付ではない。

```powershell
python -m research.forward_restart_receipts `
  --cycle-id sample001 `
  --asof-utc 2026-11-10T01:00:00Z `
  --report out/forward_shadow_watch_001.json `
  --out out/receipt_001.json

python -m research.forward_source_intake `
  --mt4 out/mt4_export_series_001.json `
  --out out/source_intake_001.json

python -m research.forward_shadow_campaign `
  --watchdog out/forward_shadow_watch_001.json `
  --intake out/source_intake_001.json `
  --receipt out/receipt_001.json `
  --out out/shadow_campaign_001.json
```

次回のレシート作成には`--previous out/receipt_001.json`を与える。単純なSHA連結は信頼された外部時刻やオペレーターの不正変更不能性を証明しない。再起動後に過去レシートが存在しない場合、レシート番号1から新しい独立チェーンとなるため、**既存の取引停止ラッチが解除されたものとは見なさない**。

経済カレンダーは`--calendar path`を4区分の各スナップショットに対し繰り返し入力できる。ホスト名の文字列検査はDNS/TLSの真正性を確証しない。URLに掲載された架空のイベントについて実在性を認定しない。

**絶対不変条件**：`runtime_go_no_go=NO_GO`、`safety_hold_latched=true`、`real_orders_permitted=false`、デモ発注無効。証券会社への注文・口座接続・MT4スクリプト実行、外部APIへの通信、課金AI呼出、Windowsタスク登録は追加していない。

正式リスク条件（取引0.5%、同時1%、日次1.5%、DD 2/3/4/5%など）の本番取引への適合認定とは無関係。実デモ運用開始にはMT4実機、独立データ/時計照合、リスクエンジン検証、ユーザー承認が依然必要。
