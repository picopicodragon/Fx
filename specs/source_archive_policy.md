# 設計対話の原議アーカイブ・抽出方針（Q113）

> **採用済み方針：C／仕様v11.3**
> **現状：ローカルの完全な原議アーカイブは未作成・未確認。** GitHubへの初期登録は、現会話で直接確認できるQ113の短い決定抜粋に限る。

## 原本と公開範囲の区分

| 区分 | 管理先 | 内容 |
|---|---|---|
| 原議全文（一次記録） | **ユーザーのWindows PC上、Gitリポジトリ外** | 元の対話記録を改変せず保存。必要に応じファイルのSHA-256を控える。GitHubへアップロードしない |
| 決定抜粋（照合済み） | **Private GitHubリポジトリ** | 必要なユーザーの決定発言だけを確認・抽出。仕様ID・発言位置・取得方法・機密審査結果・照合状態を付与 |
| マスター仕様 | GitHub `MASTER_SPEC.md` / `specs/` | 決定抜粋を解釈した仕様。原議そのものとして扱わない |
| 安全仕様の本人承認 | `DECISIONS.md`・照合台帳 | 原議との照合、未決事項の解消、本人の明示承認。PRマージと別 |

**「原議アーカイブをローカルへ保存する」という方針の決定と、「実際にWindows PCへ保存できた」という事実は別です。** 現時点で、ユーザーPC内の保存は行われていません。

## 作成・取り込みの手順

1. Windows PCのGitリポジトリ**外**へ、設計対話の原文を保存する。ChatGPTから出力/エクスポートする場合、内容に他の会話・氏名・金融情報・認証情報が混在しないか確認する。Web版の全対話が現在この開発環境へ自動提供されるわけではない。
2. 原本は編集せず保管。保存場所・アーカイブ日時・ファイルサイズ・SHA-256（任意の整合性証拠）を**ローカルで管理**する。ローカル絶対パスやユーザー固有情報はGitHubへ送らない。
3. 決定事項ごとに、原本から**必要最小限のユーザー発言**を抜粋。Q番号、原議内の識別位置、日時（確認できる場合）、原文、参照元を添付する。長文の全文転載を避ける。
4. 抜粋内容と原本が一致するか照合し、氏名・メール・電話・口座番号・APIキー・機密情報・第三者著作物などを確認する。伏せ字にした場合は原本と同一ではないことをメタデータに明記する。
5. 審査済みの抜粋を `specs/source_excerpts/Qxxx.md` へ配置し、`specs/source_evidence.json` に参照を登録する。
6. AIは抜粋から仕様との一致・矛盾・欠落を検査するが、**原議未取得なら「確認済み」としない**。独立して確認できた発言に限り `source_kind=ORIGINAL` へ更新できる。
7. 安全重要仕様は `specs/reconciliation_registry.json` の審査と本人の承認を別途経てから実装用に確定する。**原議抜粋の登録だけで安全重要仕様を承認済みにはしない**。

## データ形式の最小要件

`specs/source_evidence.json` の各レコードには少なくとも以下を記録する。

- `question_id`：例 `Q113`
- `excerpt_path`：検証済み抜粋のリポジトリ内相対パス
- `source_kind`：`ORIGINAL` / `SUMMARY_ONLY` / `UNAVAILABLE`
- `verification`：`DIRECT_CHAT` / `LOCAL_ARCHIVE` / `PENDING`
- `archive_locator_status`：原本への持続的参照の整備済み/未完了を区別
- `source_locator`：個人情報を含まない、原議の所在を確認できる記述（なければnull）
- `confidentiality_review`：抜粋内容のGitHub登録適否の状態
- `owner_approved_for_safety`：安全重要仕様の本人承認とは別項目であり、デフォルト `false`

**ソフトウェアは原文の存在・参照の整合性を検査できても、抜粋の真正性、文脈上の正しさ、漏れ、本人による承認を自動保証できません。**

## 初期段階の運用上の制約

- このGitHubリポジトリに全対話を自動収集する仕組みは作成しません。
- 原議全文のエクスポートを全件そのままコミットしないでください。Private repoでも個人情報と鍵は非公開のまま管理します。
- `specs/source_excerpts/Q113.md` は**この会話で直接示された第113問のユーザー決定文のみ**を載せます。
- Q1〜112の抜粋は未登録。過去のAI要約だけを参照して原文のように作成することは禁止します。
- Q113は保存形式の方針に関する決定であり、安全モジュールの実装承認ではありません。

## Codexへの引き継ぎ

Codexは、原議の所在が不明な場合に推測で決定の原文を生成せず、`specs/source_evidence.json` の証拠状態を確認してください。新規の抜粋を登録する際は保護対象の情報を審査し、対応仕様と差分を記録してください。
