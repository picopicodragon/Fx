## 1. 正式に採用する構成

1. **主推論AI**：当初はOpenAIの通常の推論API（Responses API等）を利用して、金融政策・経済指標・市場予想・織り込み・反証可能性を解釈し、根拠と反証条件を伴うマクロ仮説を構築する。主推論インターフェースは特定のAPI／モデルIDに依存させない。
2. **独立反証AI**：主推論とは別呼び出し・別審査プロセスで、Q26～29のAPPROVED / REVISION / REJECTED / PENDINGを判定する。仮説作成結果をそのまま承認扱いにしない。Q29のREVISION最大2回等は維持する。使用可能なモデルはQ92～98の品質検証・本人承認済みプールに限定する。
3. **補助判断AI 第1候補：TypeSafe AI Jev**。優先してオフライン比較し、ニュース重要度・追加調査要否・再分析優先度等、範囲が限定された構造化判断に適するか検証する。
4. **補助判断AI 第2候補：OpenAI Decisions API**。Jevと同じ固定入力データ・評価規約で比較する。独立検証のない数値優位性や「高い確信度」を売買成功確率とみなさない。
5. **主従関係**：JevとDecisions APIは導入前の比較候補であり、両者の常時併用、両者の同時稼働、Jevの本番採用、Jevへの売買権限移譲は決定していない。将来は双方不採用も可能。主推論・反証を構造化判定だけで置換しない。
6. **最終発注可否**：Python等の決定論的・独立した資金管理と安全検証、既存ポジション・イベント停止・注文状態・サーバー側SL確認で制御する。補助AIの評価でハード制約を解除しない。

## 2. 交換可能なインターフェースの設計

同一の業務意味を持つ**内部ドメイン契約**を先に定義し、プロバイダー固有形式の変換は各アダプター内へ隔離する。以下は設計対象の概念であり、完成済みのJSONスキーマやコードではない。

| 内部インターフェース | 入力・出力上の役割 | 実装状態 |
|---|---|---|
| `MacroResearchProvider` | 出典・時刻付き検証データ → マクロ仮説・根拠・反証条件・有効期限案 | 未実装 |
| `IndependentReviewProvider` | 仮説・反証用証拠 → Q28四段階判定・修正要求・懸念点 | 未実装 |
| `BoundedDecisionProvider` | 確定した入力状態・有限選択肢／評価尺度 → 選択／スコア／条件確率 | 未実装 |
| `ProviderRegistry` | 用途・承認状態・検証版・予算・許可モデル集合による明示的なルーティング | 未実装 |

- 実装時の共通結果には、処理ID、使用した役割、プロバイダー/モデルの識別子と固定バージョン、プロンプト／質問規約版、入力スナップショット、根拠ソースのURLと取得時刻、出力型、呼び出し時刻、APIコスト・使用量、結果の検証状態を記録する。機密データの保存は最小限とし、ログへの認証情報露出を禁止する。
- Jevの `noul/choice/score` とOpenAI Decisionsの `predicate/choice/score` は**名前や返却形式が同一ではない**。各アダプターが厳密に型・選択肢・範囲・欠損・単位を検証し、ドメイン契約へ正規化する。
- 確率／confidenceは**条件付き判断の参考値**であり、予測収益率、取引成功確率、執行承認の代替にしない。確率較正・市場外挿・データ分布変化を別途評価する。
- 障害・タイムアウト・無効な出力・未承認モデル・重要な評価相違がある場合、自動的に別プロバイダーへ切り替えて承認済みと扱わない。許可された再評価経路と安全条件が未成立ならPENDING/REJECTEDまたは新規発注停止としてFail Closedにする。
- 価格計算、ロット・損失上限、SL、状態照合、復旧ゲートはAIアダプターの外部に置く。Q195–199の結果不明時再送禁止も独立維持する。

## 3. 運用前の比較評価

- 第1段階：JevとDecisions APIを**実売買とは隔離したオフライン環境**で評価。通常OpenAI推論APIは基準分析器として継続する。
- 入力：過去の公開済み経済イベント・ニュース、当時入手可能だった情報だけを用いたタイムスタンプ付き事例、情報欠落・相反ニュース・改訂データ・データ汚染事例、無関係な指示混入例。
- 比較：分類の再現率/適合率、重要事象の見落とし、保留・棄却の適切さ、信頼度と正答頻度の較正、入力順序/言い回しへの感度、モデル更新時の再現性、遅延、可用性、１件・月間の推定費用。
- 第2段階：未使用事例と模擬リアルタイム・ペーパー環境で対抗比較。Q95～98に沿う。重大事実誤認・捏造・反証見落としを優先的に除外する。
- **合格閾値・採用モデルID・具体プロバイダー認証・費用の最新条件は未決**。外部公表の性能数値を合格保証とみなさず、実測の根拠が揃うまで本番ルートへ接続しない。
- モデル選定・有効化・重要な更新・デフォルトの切替はQ93/Q98/Q107の本人明示承認、記録、必要な回帰試験の対象。設計採用のみでモデル本番承認とはならない。
